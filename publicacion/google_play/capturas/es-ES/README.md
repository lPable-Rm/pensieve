# Capturas de Google Play — español

Estado: **borrador pendiente de aprobación visual**.

Las capturas originales del dispositivo se conservan fuera de `final/`. Las
cuatro composiciones finales propuestas están en `final/`, en PNG opaco de
24 bits y con un tamaño de 1080 × 1920 píxeles.

## Orden y texto alternativo

1. `01_recordatorios_es.png`
   - Cabecera: `Tus recordatorios, siempre a la vista`.
   - Texto alternativo: Pantalla principal de Nolvida con tres recordatorios y
     botones para completar, crear una nota o usar la voz.
2. `02_captura_es.png`
   - Cabecera: `Captura por voz o texto`.
   - Texto alternativo: Estado vacío de Nolvida con opciones para crear una
     nota o capturar un recordatorio por voz.
3. `03_widget_es_v2.png` — versión recomendada.
   - Cabecera: `Pulsa el widget y dilo. Sin abrir la app. Sin perder tiempo.`.
   - Texto alternativo: Widget de Nolvida en estado Grabando, con control para
     detener la captura y una onda de voz.
4. `04_notificaciones_es_v3.png` — versión recomendada.
   - Cabecera: `Tus recordatorios, siempre a la vista en la pantalla de tu
     móvil.`.
   - Texto alternativo: Notificación agrupada de Nolvida que mantiene visibles
     tres recordatorios pendientes.

Las variantes `04_notificaciones_es.png` y `04_notificaciones_es_v2.png` se
conservan temporalmente para comparar y no deben subirse si se aprueba la
versión 3.

La primera variante `03_widget_es.png`, con la cabecera
`Habla sin abrir la app`, también se conserva temporalmente para comparar y no
debe subirse si se aprueba la versión 2.

Las composiciones se generaron a partir de capturas reales. No deben añadirse
controles, funciones, premios, precios, valoraciones ni llamadas a descargar.
Después de aprobar este juego, se localizarán las cabeceras y la interfaz para
los otros cinco idiomas de la ficha.
